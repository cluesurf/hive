# Tessellation Generation

How to generate {p,q} tilings in 2D and {p,q,r} honeycombs in 3D.

## Overview

A **{p,q} tiling** fills a 2D space with regular p-gons, where q meet at
each vertex. A **{p,q,r} honeycomb** fills 3D space with {p,q} cells,
where r cells meet around each edge.

The geometry is determined by the Schläfli symbol:

| Condition      | 2D Geometry | 3D Geometry |
| -------------- | ----------- | ----------- |
| (p-2)(q-2) < 4 | Spherical   | Spherical   |
| (p-2)(q-2) = 4 | Euclidean   | Euclidean   |
| (p-2)(q-2) > 4 | Hyperbolic  | Hyperbolic  |

For 3D, the condition involves the angular defect at edges.

## 2D Tessellations

### Mathematical Foundation

Each {p,q} tiling has an associated **triangle group** Δ(2,p,q) with
angles π/2, π/p, π/q at vertices. The fundamental domain is this
triangle, and the tiling is generated by reflections across its edges.

```
        A (π/p angle)
       /\
      /  \
     /    \
    /      \
   /________\
  B          C
(π/2)      (π/q)
```

- Edge AB: reflection generates p-fold symmetry
- Edge BC: reflection generates 2-fold symmetry (edge midpoint)
- Edge AC: reflection generates q-fold symmetry

### Key Measurements

For a {p,q} tiling with unit edge length:

```typescript
// Angle at center of p-gon
const centralAngle = (2 * Math.PI) / p

// Interior angle of p-gon
const interiorAngle = ((p - 2) * Math.PI) / p

// Angle defect (determines curvature)
```

### Generator Matrices

Three reflection generators for the triangle group:

```typescript
interface TilingGenerators {
  // Reflection across edge opposite to π/p vertex
  rA: Matrix

  // Reflection across edge opposite to π/2 vertex
  rB: Matrix

  // Reflection across edge opposite to π/q vertex
  rC: Matrix
}
```

### Tile Data Structure

```typescript
interface Tile {
  // Unique identifier (the word that generates this tile)
  id: string

  // Transformation from center tile to this tile
  transform: Matrix

  // Center point in geometry coordinates
  center: Point

  // Vertices (computed from center + transform)
  vertices: Point[]

  // Adjacent tiles (by edge index)
  neighbors: (Tile | null)[]

  // Distance from origin tile (in tile steps)
  depth: number
}
```

### Tile Address (Word Representation)

Each tile is identified by a "word" - a sequence of generator
applications from the center tile.

```typescript
class TileAddress {
  // Sequence of generator indices
  // For triangle group: 0=rA, 1=rB, 2=rC
  word: number[]

  // Canonical form (reduced word)
  canonical(): TileAddress {
    // Apply relations:
    // rA² = rB² = rC² = identity
    // (rA·rB)^p = identity
    // (rB·rC)^2 = identity
    // (rA·rC)^q = identity
    return this.reduce()
  }

  // Convert to transformation matrix
  toMatrix(generators: TilingGenerators): Matrix {
    let m = identity()
    for (const g of this.word) {
      m = compose(m, generators[g])
    }
    return m
  }

  // Get center point
  toPoint(generators: TilingGenerators, geom: Geometry): Point {
    const m = this.toMatrix(generators)
    return geom.applyMatrix(m, geom.origin())
  }
}
```

### Tile Generation Algorithm

Breadth-first expansion from center tile:

```typescript
class TilingGenerator {
  private geometry: Geometry
  private generators: TilingGenerators
  private p: number
  private q: number

  // All generated tiles, keyed by canonical word
  private tiles: Map<string, Tile> = new Map()

  // Queue for BFS expansion
  private frontier: Tile[] = []

  constructor(p: number, q: number, geometry: Geometry) {
    this.p = p
    this.q = q
    this.geometry = geometry
    this.generators = this.computeGenerators(p, q)

    // Create center tile
    const center = this.createCenterTile()
    this.tiles.set('', center)
    this.frontier.push(center)
  }

  // Generate tiles up to given depth
  generate(maxDepth: number): Tile[] {
    while (this.frontier.length > 0) {
      const tile = this.frontier.shift()!

      if (tile.depth >= maxDepth) continue

      // Expand each edge
      for (let edge = 0; edge < this.p; edge++) {
        this.expandEdge(tile, edge)
      }
    }

    return Array.from(this.tiles.values())
  }

  // Generate tiles within distance from origin
  generateWithinDistance(maxDistance: number): Tile[] {
    while (this.frontier.length > 0) {
      const tile = this.frontier.shift()!

      // Check if center is within distance
      const dist = this.geometry.distance(
        this.geometry.origin(),
        tile.center,
      )
      if (dist > maxDistance) continue

      for (let edge = 0; edge < this.p; edge++) {
        this.expandEdge(tile, edge)
      }
    }

    return Array.from(this.tiles.values())
  }

  private expandEdge(tile: Tile, edge: number): void {
    // Compute the reflection that crosses this edge
    const reflection = this.edgeReflection(tile, edge)

    // Compute new tile's word
    const newWord = this.appendAndReduce(tile.id, reflection)

    // Check if already exists
    if (this.tiles.has(newWord)) {
      // Link as neighbor
      tile.neighbors[edge] = this.tiles.get(newWord)!
      return
    }

    // Create new tile
    const newTile = this.createTile(newWord, tile.depth + 1)
    this.tiles.set(newWord, newTile)
    this.frontier.push(newTile)

    // Link neighbors
    tile.neighbors[edge] = newTile
    newTile.neighbors[this.oppositeEdge(edge)] = tile
  }

  private createCenterTile(): Tile {
    const vertices = this.computeTileVertices(identity())
    return {
      id: '',
      transform: identity(),
      center: this.geometry.origin(),
      vertices,
      neighbors: new Array(this.p).fill(null),
      depth: 0,
    }
  }

  private createTile(word: string, depth: number): Tile {
    const address = TileAddress.fromString(word)
    const transform = address.toMatrix(this.generators)
    const center = this.geometry.applyMatrix(
      transform,
      this.geometry.origin(),
    )
    const vertices = this.computeTileVertices(transform)

    return {
      id: word,
      transform,
      center,
      vertices,
      neighbors: new Array(this.p).fill(null),
      depth,
    }
  }

  private computeTileVertices(transform: Matrix): Point[] {
    // Start with vertices of center tile (regular p-gon)
    const baseVertices = this.regularPolygonVertices(this.p)

    // Transform each vertex
    return baseVertices.map(v =>
      this.geometry.applyMatrix(transform, v),
    )
  }

  private regularPolygonVertices(p: number): Point[] {
    const vertices: Point[] = []
    const angleStep = (2 * Math.PI) / p

    for (let i = 0; i < p; i++) {
      const angle = i * angleStep
      // Compute vertex at circumradius distance from origin
      const direction = [Math.cos(angle), Math.sin(angle), 0]
      vertices.push(
        this.geometry.pointOnGeodesic(
          this.geometry.origin(),
          direction,
          this.circumradius,
        ),
      )
    }

    return vertices
  }
}
```

## 3D Tessellations (Honeycombs)

### Mathematical Foundation

A {p,q,r} honeycomb fills 3D space with {p,q} polyhedral cells, where r
cells meet around each edge. The associated group is a Coxeter group
with 4 generators.

```
Coxeter diagram for {p,q,r}:

  o---p---o---q---o---r---o
  s0      s1      s2      s3

Relations:
- si² = identity
- (s0·s1)^p = identity
- (s1·s2)^q = identity
- (s2·s3)^r = identity
- (s0·s2)² = (s0·s3)² = (s1·s3)² = identity
```

```typescript
interface Cell {

  // Vertices of the polyhedron

  // Faces (each face is a list of vertex indices)
  faces: number[][]

  // Adjacent cells (by face index)

  // Distance from origin cell
  depth: number

  // Vertices (in order)
  vertices: Point[]

  // Normal vector
  normal: Point

  // Adjacent cells (this cell and neighbor)
```

## Optimization

### Caching Transformations

```typescript
class TransformCache {
  private cache: LRUCache<string, Matrix>

  get(word: string): Matrix | undefined {
    return this.cache.get(word)
  }

  set(word: string, matrix: Matrix): void {
    this.cache.set(word, matrix)
  }

  // Compute incrementally from parent
  computeFromParent(parentWord: string, generator: number): Matrix {
    const parentMatrix = this.get(parentWord) ?? identity()
    const genMatrix = this.generators[generator]
    return compose(parentMatrix, genMatrix)
  }
}
```

### Level-of-Detail

```typescript
interface TilingLOD {
  // Full detail near camera
  nearTiles: Tile[]

  // Simplified (merged) tiles at medium distance
  midTiles: SimplifiedTile[]

  // Just colored regions far away
  farRegions: Region[]
}

class LODGenerator {
  generate(camera: Camera, tiling: TilingGenerator): TilingLOD {
    const allTiles = tiling.generateWithinDistance(camera.farPlane)

    return {
      nearTiles: allTiles.filter(
        t => this.distanceToCamera(t) < nearThreshold,
      ),
      midTiles: this.mergeTiles(
        allTiles.filter(
          t =>
            this.distanceToCamera(t) >= nearThreshold &&
            this.distanceToCamera(t) < midThreshold,
        ),
      ),
      farRegions: this.regionize(
        allTiles.filter(t => this.distanceToCamera(t) >= midThreshold),
      ),
    }
  }
}
```

### Instanced Rendering

All tiles share the same geometry, just different transforms:

```typescript
interface TileInstance {
  transform: Matrix // 3x3 for 2D, 4x4 for 3D
  color: [number, number, number, number]
  tileId: number // For picking
}

class TileRenderer {
  private baseGeometry: Float32Array // Single tile vertices
  private instanceData: Float32Array // Per-tile transforms

  render(tiles: Tile[]): void {
    // Update instance buffer
    this.updateInstances(tiles)

    // Single draw call for all tiles
    gl.drawArraysInstanced(
      gl.TRIANGLES,
      0,
      this.vertexCount,
      tiles.length,
    )
  }
}
```

## API Summary

```typescript
// Create a tiling
const tiling = new TilingGenerator(7, 3, new Hyperbolic2D())

// Generate tiles
const tiles = tiling.generate(10) // depth 10
// or
const tiles = tiling.generateWithinDistance(5.0) // hyperbolic distance 5

// Access tiles
const center = tiling.getTile('') // center tile
const neighbor = tiling.getTile('0') // first neighbor

// Navigate
const tile = tiling.getTile('0120')
const adjacent = tile.neighbors[2] // third edge neighbor

// Convert to coordinates
const point = tile.center
const vertices = tile.vertices

// For rendering
const instances = tiles.map(t => ({
  transform: t.transform,
```
